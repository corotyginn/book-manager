# 📚 Book Manager

A full-stack web application for managing your personal book collection.
Add books, view your library, delete entries, and filter by author — all
in a clean, single-page interface.

---

## ✨ Features

- **Add books** — form with title, author, and optional publication year
- **View library** — dynamically loaded list from the database
- **Delete books** — one click to remove an entry
- **Filter by author** — live search on the client side
- **Persistent storage** — SQLite database via SQLAlchemy ORM
- **No page reloads** — asynchronous updates with Fetch API

---

## 🛠 Tech Stack

| Layer      | Technology                          |
